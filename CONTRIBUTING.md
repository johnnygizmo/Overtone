# Contributing

## Code

- Run `flutter analyze`, `dart format .`, `dart run tools/check_deps.dart`, and
  the tests before opening a pull request.
- Code contributions are accepted under GPL-3.0.
- Keep package dependency directions as described in
  [Planning/PLAN.md](Planning/PLAN.md) section 2.1.

## Content

- Lessons, exercises, and other notes live in `content/`.
- Content contributions are accepted under CC BY-SA.
- Run `overtone content validate` before opening a pull request.
- Do not contribute media (audio, images, scores) unless you own it or it is
  under a compatible license; record the source and license in the pull
  request.
